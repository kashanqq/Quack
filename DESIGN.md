# System Design: Платформа подбора вузов и трекинга поступления (AI Roadmap)

## 1. Обзор и цели (Overview & Goals)

### 1.1. Проблема
Абитуриенты тратят недели на сбор разрозненной информации: проходные баллы, дедлайны подачи документов, визовые требования, вступительные экзамены и учет льгот/олимпиад. Нет единого инструмента, который строит интерактивный пошаговый маршрут под профиль конкретного человека.

### 1.2. Цели (Goals)
- Персонализированный подбор 3–5 целевых вузов (Dream / Target / Safety) на основе входного профиля (баллы, бюджет, специальность, локация).
- Генерация интерактивного графа/дорожной карты (Roadmap) с дедлайнами, этапами сдачи тестов и чек-листом документов.
- Оркестрация мультиагентного пайплайна: сбор требований вуза $\rightarrow$ валидация данных $\rightarrow$ построение таймлайна.
- Стриминг прогресса генерации карты в UI через Server-Sent Events (SSE) или WebSocket, чтобы пользователь не ждал с «зависшим» экраном.

### 1.3. Не-цели (Non-Goals)
- Автоматическая подача документов в вузы от имени пользователя через гос. порталы (в MVP — только инструкция и прямые ссылки).
- Прямая интеграция с банками для оформления образовательных кредитов.

## 2. UI/UX & Дизайн-система

### 2.1. Цветовая палитра
Интерфейс строится на строгой, академичной и современной темной теме:
- **Background / Dark Gray:** `#121417` (основной фон), `#1E2228` (карточки и панели).
- **Text / Contrast:** `#F4F5F7` (основной текст), `#9CA3AF` (второстепенный текст/плейсхолдеры).
- **Primary Accent / Muted Gold:** `#DBAA40` (акцентные кнопки, маркеры дедлайнов, прогресс-бар, активные ноды на карте).
- **Border / Dividers:** `#2E3440`.

### 2.2. Ключевые экраны
1. **Onboarding / Questionnaire:** Пошаговый ввод баллов (тесты, GPA), интересов, языковых сертификатов и бюджета.
2. **Dashboard / Recommendations:** Сравнение предложенных вузов с фильтрацией по шансам поступления.
3. **Interactive Roadmap View:** Канбан/Таймлайн-граф этапов (с делением по месяцам и статусам выполнения).
