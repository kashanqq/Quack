Как устроен Quack под капотом
Шесть слоёв — от интерфейса ученика до внешних источников — и правило, которое держит систему честной: языковая модель понимает и объясняет, детерминированные правила единственные считают и пишут в данные.

правило §7
Модель — не источник правды и не на пути пересчёта. Она читает факты и пишет изменения только через инструменты детерминированного слоя (L4); сама она не имеет доступа на запись в граф, кэш или БД (L5). Всё, что в ответе выглядит как число, требование или дата, — результат вызова инструмента, с источником рядом.

L3
ИИ / языковая модель
Понимает человека и объясняет — не источник фактов

Ассистент «Подбор»
Извлекает анкету и черты, ведёт резюме предпочтений, диалог по политике: не больше двух вопросов за ход

Ассистент-репетитор
Чат топика и чат сета; уровень подсказки из профиля, эскалация после второй неудачи; работает поверх собранного контекста

Наблюдатель за чатом
Отдельно от ответа, асинхронно; пишет свидетельства о навыках по правилам memory-architecture

Генератор текста
Резюме понимания · «почему реалистично» / «подходит тебе» · гайдлайны топиков · отчёт по сету — кэшируются по хэшу входа

Экстрактор программ
Поля вуза из найденных страниц: требования, стоимость, дедлайны, среда — с URL и датой

Стретч-генератор задач
Только когда пул датасета исчерпан; проходит те же инварианты, что и ручные задачи (§5.4)

L4
Детерминированные правила
Мгновенно, повторяемо, сводимо к источнику — без модели

Скоринг реалистичности
Жёсткие факторы (балл / бюджет / грант / сроки) → статус → три словесных уровня; ранжирование по приоритетам ученика

Требования · Вехи · Конфликты
Выводятся из сохранённых программ и календарей экзаменов; конфликты — по явным правилам совпадения дат

Очередь навыков → Сеты
Ранжирование по потребности и срочности, сборка сета, дедлайн из трудоёмкости и часов в неделю, прогноз готовности

Сборщик и подсчёт моков
По ExamFormat: модули, доли типов заданий, распределение по областям и сложности, правила зачёта

Свидетельства → состояние навыков
Агрегация верно/неверно/частично/таймаут в состояние навыка и статус заблуждения — детерминированно

Планировщик Quack
Порядок и срочность рекомендаций, ритм выдачи раз в 1–2 дня, дни активности

Фоллбек-контроллер
Таймауты по каждой генеративной функции, явный статус «недоступно», выбор кэшированной версии (§6.3)

02
Реактивность: «изменил → изменилось»
Любое изменение источника правды детерминированно пересчитывает всё производное — без обращения к модели. Разброс от источника до экрана — тот же путь L5/L1 → L4 → L1.

Источник изменился	Слой L4 пересчитывает	Что видит ученик на L1
Анкета: бюджет, страна, грант, направление, баллы	жёсткие факторы, оценки реалистичности, порядок подборки, оценки сохранённых	новый порядок и статусы сразу; ассистент называет сдвиг
Черты / резюме предпочтений	мягкое соответствие — в фоне (L3, кэш по хэшу)	порядок внутри уровней обновляется, когда готово; до этого — пометка
Дата теста, целевой балл, часы в неделю	требования, вехи, очередь навыков, сеты, прогноз	новые дедлайны сетов и прогноз; при риске срыва — рекомендация по темпу
Сохранил / убрал программу	экзамены в подготовке, требования, вехи, сеты, конфликты	появление/исчезновение экзамена с показом последствий; модель знаний не трогается
Ответ на задачу, мок	состояние навыков, заблуждения, прогресс сета, прогноз, оценки сохранённых	результат сразу; состояние навыка и прогноз обновлены
Реплика в чате подготовки	свидетельства — асинхронно (L3 наблюдатель → L4)	«модель обновлена» через несколько секунд, раскрываемо до задачи
Ручная смена сета, состава, дедлайна	очередь навыков, прогноз	предупреждение, если стало нереалистично
Отметка вехи	прогресс по вехам, конфликты	конфликт снят или остался с вариантами
«Не согласен» с заблуждением	сеты, контекст чата	заблуждение исчезает до новых свидетельств
Принятие рекомендации Quack	та же цепочка, что и ручное изменение источника	вся цепочка выше, начиная с изменённого источника

04
Деградация по слоям (§6.3)
У каждой генеративной функции — таймаут, предгенерация и явное состояние «недоступно»; фоллбек не должен понадобиться в момент работы.

Недоступен слой	Статус	Что происходит
L3 — языковая модель	частично	L4 работает без потерь: подборка, реалистичность, сеты, прогноз, моки, свидетельства из задач. Из кэша — резюме, объяснения, гайдлайны, «подходит тебе», с пометкой «сохранённая версия». Отключаются явно: оба чата, наблюдение, мягкое соответствие для новых программ, извлечение новых программ, персональные узлы, отчёт по сету — статус «ассистент временно недоступен»
L5 — модель знаний ученика	частично	Подбор, сохранённые, вехи работают полностью. Сеты — в статическом порядке канонической карты, с пометкой. Ответы копятся как события и применяются при восстановлении. Прогноз — «недоступен»
L6 — веб-поиск	частично	Подбор идёт по кэшу и полу проверенных программ, с пометкой «показаны только проверенные программы»
L5 — база знаний о поступлении	выключен фрагмент	Ассистент не отвечает на вопросы о правилах экзаменов и поступления — говорит, что не может проверить; всё остальное работает
Ничего не сохранено / ничего не подошло	обработано правилом	Ни один экран не пустует без объяснения и следующего действия: ведёт в чат подбора или показывает, какой фактор всё отсёк
