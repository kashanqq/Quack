# B1 — движок и граф

Раздел фазы 1, роль **B1** (движок и граф) из `20-B1.md`. Этот документ описывает
вклад B1 в продукт и связь с другими слоями.

## Что сделано

### Граф Neo4j — `backend/app/graph/`

- `labels.py` — все метки и типы связей (`Exam`, `Skill`, `Misconception`, `KnowledgeState`, `Evidence`, ...)
- `schema.cypher` + `schema.py` — схема (индексы, constraints, vector-index для эмбеддингов заблуждений), `apply_schema(driver, dim)`
- `client.py` — жизненный цикл Neo4j-драйвера. **Soft-fail**: `create_driver` возвращает `None`, если база недоступна, `close_driver(None)` — no-op
- `queries/canonical.py` — 8 read-запросов: карта навыков, пререквизиты, формат экзамена, заблуждения по навыку, шаблоны по навыку, `is_dag`
- `queries/personal.py` — `ensure_student`, `get_state`, `get_states`, `upsert_state`, `merge_evidence` + стабы для Ф2
- `queries/kb.py` — маршруты поступления, даты тестов, факты о экзаменах
- `context.py` — стаб `build_topic_context` для Ф2

### Правила — `backend/app/knowledge/`

- `hlr.py` — модель забывания (half-life regression): `recall_p`, `updated_half_life`, `updated_p_at_obs`, `confidence`, `spread_factor`, `due_at`, `apply_evidence`
- `weights.py` — ярусы доверия и веса свидетельств из §4.3
- `misconceptions.py`, `reconcile.py` — стабы для Ф2

### Задачи из шаблонов — `backend/app/tasks/`

- `evaluate.py` — безопасный `eval_expr` через `sympy.parse_expr` с белым списком имён (никакого `eval`)
- `render.py` — подстановка `{name}` в stem и solution, форматирование значений (fraction, decimal, integer)
- `generate.py` — генерация экземпляров из шаблона по seed, `validate_template` с инвариантами §3.4
- `generators.py` — реестр непараметрических генераторов
- `answer.py` — проверка ответов ученика (`grade` для mcq4/mcq5/numeric/multi_select)

### Эмбеддинги — `backend/app/embeddings.py`

- `Embedder` — ленивая обёртка над `sentence-transformers` (модель `intfloat/multilingual-e5-small`, 384 dim)

### Загрузчики в граф — `backend/app/seed/`

- `skills.py` — карта навыков + области + HAS_SKILL + REQUIRES
- `exam_formats.py` — секции и scale table экзаменов
- `misconceptions.py` — библиотека заблуждений с эмбеддингами
- `templates.py` — шаблоны задач (`TaskTemplate`, `TESTS`, `TRAPS`) + `validate_templates(path)`
- `knowledge_base.py` — факты (Fact) и маршруты поступления (Country–Route–Requirement)

Все загрузчики идемпотентны (MERGE по id), совместимы с `scripts/seed.py` (B3).

### Данные — `data/`

- `skills/sat_math.json` — SAT Math: 4 области, 33 навыка, Σ весов = 44
- `skills/ent_math.json` — ЕНТ математика: 6 областей, 25 навыков, Σ весов = 50
- `exam_formats/{sat_math,ent_math}.json` — формат обоих экзаменов
- `misconceptions/library.json` — 15 типичных заблуждений
- `templates/**/*.json` — 5 шаблонов: mcq4, mcq5, numeric, multi_select, generator
- `knowledge_base/exams.json` — факты о SAT Math и ЕНТ
- `knowledge_base/routes.json` — маршруты поступления KZ, US
