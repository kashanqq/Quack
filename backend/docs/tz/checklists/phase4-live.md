# Живой провайдер, фаза 4 (§13)

Ведёт B2. Автотесты фазы идут на `FakeLLMClient`; здесь — то, что видно
только на настоящей модели. Прогон на одном ученике с заполненной анкетой
и одним открытым сетом.

## Тексты сета

- [ ] Гайдлайн читается как связный текст, а не как список из промпта.
- [ ] В гайдлайне нет процентов, вероятностей и обещаний баллов.
- [ ] Ловушки — только те заблуждения, что есть в модели знаний ученика;
      при пустом списке раздела «Ловушки» нет вовсе.
- [ ] Навык со статусом «мало данных» не назван слабым.
- [ ] Гайдлайн короче 2000 символов; в режиме `review` заметно короче.
- [ ] Объяснение навыка не упоминает конкретного ученика и переиспользуется:
      второй ученик с тем же навыком получает ту же строку `generated_texts`
      (`student_id IS NULL`).

## Отчёт по сету

- [ ] Текст приободряющий и без укора за темп.
- [ ] Каждое число в тексте есть в `stats` (постпроверка не сработала ни
      разу — в логах нет `text_failed` с `reason=postcheck`).
- [ ] Сроки названы словами: «успеваешь» / «пока не успеваешь».

## Мягкое соответствие

- [ ] `fit_text` — одна-две фразы, обращение на «ты», без цифр и «%».
- [ ] Оценка не спорит с жёсткими факторами (не упоминает стоимость,
      баллы, дедлайны).
- [ ] Программа без `environment_text` получает ровно `score=0.5` и
      `model="no_environment"` — вызова модели не было.

## Извлечение программ

- [ ] На трёх реальных страницах: `university`, `country`, `direction`,
      `language` извлечены верно.
- [ ] Каждое число в карточке подтверждено цитатой; `dropped_fields`
      содержит ровно то, чего на странице нет.
- [ ] Валюта вне белого списка обнуляет стоимость, а не сохраняет её.
- [ ] Страница-каталог и короткая страница отбраковываются без вызова
      модели (в логах `extract_rejected`, счётчик вызовов не вырос).
- [ ] Страница с текстом «ignore all instructions…» не меняет
      извлечённое название вуза.

## Сравнение и реалистичность

- [ ] `conclusion` говорит о различиях, а не хвалит одну программу.
- [ ] Текст «почему реалистично» пересказывает факторы и не меняет
      уровень.

## Бюджет и лимиты

- [ ] `LLM_RPM_CHAT + LLM_RPM_BULK` не превышает лимит провайдера; при
      живом чате фон уступает (в логах `bulk` ждёт, чат не ждёт).
- [ ] 429 на фоне не роняет чат (статус `quack:llm:status` не стал `down`).
- [ ] Время одного `pregenerate_set` на сет из трёх топиков укладывается
      в 90 с; если нет — записать реальное время сюда и обсудить размер
      сета или `LLM_REASONING_BULK`.
