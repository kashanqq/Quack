## Итог

Все семь пунктов закрыты. Пункты 1–3 — 18.09.2026 на живом ключе (2 из 3, не
3 из 3, по структурированному выводу; критерий времени до первого токена в
потоке с инструментом не пройден и остаётся открытым риском на Ф3 —
подробности в `docs/decisions/llm-provider.md`). Пункты 4–7 закрыты
19.09.2026, когда появился слой B3: API поднимается локально
(`uv run uvicorn app.main:create_app --factory`), миграции применены,
`scripts/seed.py` создал демо-ученика, и всё проверялось curl'ом без фронта.

Единственная оговорка по методу — в пункте 5: «отключить сеть» заменено на
подмену `LLM_BASE_URL` на закрытый порт. Физическое отключение сети на
рабочей машине ломает и Postgres с Neo4j в Docker, и сам прогон, а путь
деградации в клиенте один и тот же (`APIConnectionError` → счётчик ошибок →
`quack:llm:status = down`), поэтому проверялся именно он.

Сопутствующее наблюдение (не пункт чек-листа): `load_prompt` берёт старшую
версию, поэтому после появления черновиков Ф3 эхо-чат подбора уже идёт с
`selection_v3.md`, а чат подготовки — с `tutor_v2.md`, в котором есть
незаполненный `{{learner_model}}`. `router.run_chat` передаёт `prompt.text`
без `render`, так что до проводки `get_learner_context` в Ф3 в системный
промпт репетитора попадает буквальный плейсхолдер. На Ф2 это косметика
(эхо-режим), на Ф3 — то место, где блок должен подставляться. Записано в
`docs/sync-log.md`.
