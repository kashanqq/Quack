# Quack! — frontend

Интерфейс Quack!: лендинг и раздел «Выбор» с чатом, профилем ученика, подборкой и сравнением программ.

## Стек

- [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- React 19, TypeScript
- CSS Modules (без UI-библиотек и Tailwind)
- Шрифты через `next/font/google`: Intel One Mono, Raleway, Inter, Khula, Montserrat Alternates
- Иконки — [Lucide](https://lucide.dev/) (SVG в `public/assets/icon-*.svg`)

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
npm run start    # запуск собранного приложения
```

## Страницы

| Путь | Что там |
|---|---|
| `/` | Лендинг: хэдер, анимированный роадмап, кнопка «Let's go» |
| `/choice` | Раздел «Выбор»: чат с ассистентом, «Как я тебя вижу», программы, история чатов. Переключатель на «Подготовку» (пока заглушка) |

Переходы между страницами идут через загрузку с уткой, а по экрану примерно раз в минуту пролетает утка.

## Что имитируется и где подключать бэкенд

Сейчас всё работает без сервера:

- **Ассистент** — `src/components/choice/assistant.ts`. Реплики разбираются ключевыми словами, ответы собираются по правилам. Здесь появится вызов API чата.
- **Программы и реалистичность** — `src/components/choice/programs.ts`. Данные вымышленные и помечены в интерфейсе как «демо». Здесь появятся запросы к подборке и датасету.
- **Хранение** — `localStorage` (ключи `quack-choice-workspace` и `quack-choice-layout`): профиль, избранное, сравнение, история чатов, ширины панелей. После появления бэкенда это переедет на сервер (профиль и события привязаны к пользователю, а не к устройству — см. `arch-logic.md`).

Функции в `assistant.ts` и `programs.ts` чистые и не зависят от React, поэтому их можно заменить на вызовы API, почти не трогая интерфейс.

## Адаптивность

- больше 1100px — полный вид: левая колонка, чат, «Как я тебя вижу»;
- 761–1100px (в том числе ноутбуки с масштабом 125–175%) — тот же вид с уменьшенным текстом; если панели профиля не хватает места, она открывается поверх чата;
- до 760px — телефон: одна колонка, левая колонка открывается кнопкой в хэдере.
